# Mohammad Usman — Portfolio

Personal portfolio website showcasing AI product management experience at Reliance Jio.

## Features
- Dark/light mode toggle
- Hindi/English language switch with Hindi numerals
- Recruiter mode with condensed view
- Animated count-up metrics, 3D card tilt, waveform dividers
- Contact form with mailto integration
- Resume download
- Mobile responsive with hamburger nav
- Print stylesheet

## Setup
Open `index.html` in a browser, or deploy via GitHub Pages.
